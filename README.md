# Projet Lampe

Ce petit projet Java a pour but de créer une lampe et de tester son fonctionnement.  
Il contient deux fichiers : `Lampe.java` et `ProgLampe.java`.

## Ce que fait le projet

- La classe `Lampe` représente une lampe avec une puissance et un état (allumée ou éteinte).
- Le programme `ProgLampe` crée une lampe, l’allume, vérifie son état et affiche les informations.
